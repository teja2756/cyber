# Configuration Notes

## Lab components
- Wazuh Manager
- Wazuh Dashboard
- Linux endpoint with Wazuh Agent
- Optional Kali Linux VM for controlled security testing

## Workflow
1. Install Wazuh Manager and Dashboard.
2. Install and register the Wazuh Agent.
3. Confirm agent connectivity.
4. Generate controlled authentication events in the lab.
5. Review alerts in the Wazuh Dashboard.
6. Investigate source IP, username, timestamps and related events.
7. Document the incident and response.

Only perform security testing on systems you own or are authorized to test.
