# MITRE ATT&CK T1110 — Brute Force

## Technique
**T1110 — Brute Force**

## Defensive interpretation
Repeated authentication failures can indicate attempts to guess credentials. Analysts should correlate failures with account, source, destination, time and subsequent successful authentication.

## Investigation questions
1. Which account was targeted?
2. Which source generated the failures?
3. Was a successful login observed afterward?
4. Is the source expected?
5. Are other hosts or accounts affected?
6. Are there related endpoint/network alerts?

## Mitigations
- MFA
- Account lockout and rate limiting
- Strong password policy
- Centralized authentication logging
- Detection and alerting
- Network access controls

## Evidence
Record timestamps, source/destination, usernames, authentication results and relevant SIEM alerts.
